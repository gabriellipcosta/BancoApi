# 💚 LUMI BANK

### Sistema de Banco 

O **LUMI BANK** é um banco digital para golpes.

O projeto simula um sistema de cadastro de clientes de um banco digital, com uma interface simples e moderna.

## 🚀 Tecnologias utilizadas

- Java
- Spring Boot
- MySQL
- HTML
- CSS
- JavaScript
- Spring Data JPA

## 📌 Funcionalidades

- Cadastro demonstrativo de clientes.
- Consulta de clientes cadastrados pela API.
- Integração com banco de dados MySQL.
- Interface de cadastro responsiva.

## 🎨 Interface

O projeto possui uma identidade visual baseada em tons de verde e branco, transmitindo uma aparência moderna e tecnológica.

## 📚 Objetivo

Desenvolver conhecimentos básicos sobre criação de APIs REST, integração com banco de dados e desenvolvimento de interfaces web.

## ⚠️ Aviso

Este projeto é exclusivamente acadêmico e fictício.
